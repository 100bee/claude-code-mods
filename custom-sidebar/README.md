# custom-sidebar

Claude Code 오른쪽에 붙는 사이드바 mod입니다. 컨텍스트 사용량(토큰 웨더 대체), 요금제 한도와 비용, 이름 붙인 채팅방 사이 이동, Git 변경 사항과 diff, 세션을 넘어 유지되는 메모를 한곳에서 봅니다.

## 설치

Claude Code 터미널의 프롬프트에서:

```
/plugin install custom-sidebar --marketplace 100bee/claude-code-mods
```

`Add marketplace?`에 `y`, 설치 범위는 `user`에서 Enter. 재시작 없이 바로 동작합니다. Claude Code v2.1.287 이상. Git 탭을 쓰려면 git이 설치돼 있어야 합니다.

토큰 웨더와 통합한 버전이라, token-weather를 쓰고 있었다면 `/plugin` › Installed 에서 꺼두세요.

## 여닫기

- 넓은 터미널(약 144칸 이상)에서는 세션 시작 시 자동으로 오른쪽에 붙습니다
- `/side`: 열기/닫기
- 프롬프트 위 `◧ 사이드바` 버튼: 열기/닫기 (닫혀 있을 때는 옆에 컨텍스트 %가 보임)
- 사이드바 안에서 `1` `2` `3` `4` `5`: 탭 이동, `Esc`: 프롬프트로 돌아가기, `Ctrl+X` 다음 `X`: 닫기

## 맨 위: 현재 폴더

사이드바 맨 위 한 줄에 지금 Claude Code가 열린 폴더 이름, 컨텍스트 사용률(`ctx 42%`, 어느 탭에서든 보임), `경로 복사` 버튼이 있고, 그 아래 흐린 줄에 작업 위치가 보입니다. 홈 폴더는 `~`로 줄이고(`C:\Users\user\.claude\skills` → `~/.claude/skills`), 그래도 길면 앞부분을 잘라 끝부분이 보이게 합니다. `경로 복사`는 줄이지 않은 전체 경로를 복사합니다.

## 지금 상황 (헤더 아래)

어느 탭에 있든 맨 위에 보입니다. 없는 줄은 생략됩니다.

- `⚠ 승인 필요: Bash` / `⚠ 질문에 답해 주세요`: Claude가 내 응답을 기다릴 때 (주황 굵게). 승인한 명령이 끝날 때까지 남아 있을 수 있음. 조직 보안 설정으로 classic 훅이 막힌 환경에선 승인 대기 표시만 빠짐
- `요청`: 마지막으로 보낸 요청 한 줄
- `지금`: Claude가 하는 일과 경과 시간 (`▸ Bash: 테스트 실행  12초`, `생각 중`), 끝나면 `대기 중`
- `할 일`: Claude의 할 일 목록 진행 (`■■□ 2/3 · 테스트 고치는 중`)

## 프롬프트 캐시

Claude가 답하고 나면 대화가 서버에 잠깐 저장(캐시)됩니다. 그 시간 안에 다음 메시지를 보내면 저장된 걸 바로 꺼내 써서 빠르고 사용량이 적게 들고, 지난 뒤에 보내면 대화를 처음부터 다시 읽어서 사용량이 조금 더 듭니다.

맨 위 줄의 `캐시 42분`이 남은 시간입니다. 1분 안 남으면 주황, 지나면 흐린 `캐시 만료`. 사용량 탭에 막대로도 보입니다.

유지 시간은 Claude Code가 알려주지 않아서 `hooks/register.tsx` 맨 위 `CACHE_TTL_MIN`(기본 60분)으로 시작하고, 5분 넘게 쉬었다 보낸 요청이 캐시에 맞았는지를 보고 60분/5분을 스스로 맞춥니다.

## 색

- 각 탭의 섹션 제목 오른쪽에 흐린 구분선이 폭 끝까지 이어짐

- 현재 탭은 강조색 + 굵게 + 밑줄, 나머지 탭은 흐리게 보입니다
- 강조색(현재 탭, 폴더 아이콘, 구성 막대, 턴별 그래프, Claude가 고친 파일 `●`)은 **chat-theme mod의 팔레트를 따라갑니다**. `/theme-chat winter` 처럼 바꾸면 사이드바도 바로 바뀌고, chat-theme이 꺼져 있으면 Claude 주황을 씁니다
- 초록·주황·빨강은 상태(컨텍스트·한도 게이지, Git 파일 상태)에만 씁니다. 섹션 제목은 색 없이 굵게만

## 넓혔을 때

사이드바를 넓히면 폭에 맞춰 배치가 바뀝니다.

- 막대 그래프, 구분선이 폭에 맞춰 길어짐 (막대는 너무 길면 읽기 힘들어서 최대 60칸)
- 90칸 이상이면 두 칸 배치: 사용량 탭은 왼쪽(컨텍스트·구성) | 오른쪽(턴별 증가·비용·한도), 변경 탭은 파일을 누르면 파일 목록 | diff 나란히. 파일 목록도 30개 → 60개까지
- 기준 칸 수는 `hooks/register.tsx` 맨 위 `WIDE_AT`에서 바꿈

## 탭

1. **사용량**: 컨텍스트 게이지, 항목별 구성, 턴별 증가 그래프, 세션 비용, 5시간·7일 한도와 리셋 시각. 컨텍스트는 50% 미만 초록, 50% 이상 주황, 70% 이상 빨강(알림과 `압축하기` 버튼 표시). 한도 게이지는 80% 주황, 90% 빨강
2. **채팅방**: 이름 붙여 저장한 채팅 목록, 눌러서 이동 (아래 참고)
3. **변경**: 브랜치와 앞서간/뒤처진 커밋 수, 바뀐 파일 목록(● 표시는 이번 세션에 Claude가 수정한 파일), 파일을 누르면 diff 보기
4. **활동**: 이번 대화에서 Claude가 한 일.
   - 타임라인: 메인 Claude와 서브에이전트(◆)·백그라운드 셸($)을 한 줄(레인)씩, 언제 돌았는지 시간 막대로 (진한 색 실행 중, 흐린 색 끝남, 빨강 실패). 범위는 5·10·15·30·60분 중 자동
   - 요청별 기록: 내가 보낸 요청마다 한 줄 (`✓ 테스트 좀 돌려줘` / `2분 · 도구 14 · 파일 3 · 실패 1`). 누르면 그 동안 쓴 도구가 펼쳐지고(최대 15개), 명령·파일은 눌러서 복사. 최근 5개만 보이고 `더 보기`로 30개까지
   - 기록은 이번 세션에만 있고(재시작하면 비워짐), `/clear`나 `/resume`으로 대화가 바뀌어도 비워짐
5. **메모**: 체크 가능한 메모, 남은/완료 개수, 완료 항목 한 번에 지우기

## 채팅방

지금 채팅에 이름을 붙여 저장해 두고, 버튼이나 명령어로 그 채팅으로 바로 돌아갑니다. 저장하면 입력창 옆 채팅 이름과 `/resume` 목록도 같은 이름으로 바뀌고, 채팅방으로 이동하면 그 채팅방 이름으로 바뀝니다.

- 사이드바 2번 탭에서 이름 입력 후 Enter: 현재 채팅 저장
- 목록의 `→ 이름` 누르기: 그 채팅으로 이동 (`●`는 지금 채팅)
- `/room`: 목록 보기
- `/room 이름`: 이동 (앞 글자만 쳐도 됨)
- `/room + 이름`: 현재 채팅 저장

**다른 폴더 채팅방**: 목록 아래 "다른 폴더"에 폴더별로 묶여 있고, `▸ 폴더명 (개수)`를 누르면 펼쳐집니다. `↗ 이름`을 누르면 그 폴더에서 새 터미널 창이 열리며 해당 채팅이 이어집니다(Windows Terminal, 없으면 PowerShell 창). 실행 중인 Claude Code는 작업 폴더를 바꿀 수 없어서 새 창으로 엽니다. 창을 열 수 없는 환경에서는 `cd ... && claude --resume ...` 명령을 복사해 주니 새 터미널에 붙여넣으세요. `/room 이름`도 다른 폴더 채팅방까지 찾습니다.

같은 폴더 채팅방은 지금 창에서 바로 이동합니다. Claude가 작업 중일 때는 이동하지 않으니 끝난 뒤에 누르세요.

## 설정 바꾸기

`hooks/register.tsx` 맨 위 "설정" 부분에서
- `WARN_AT`, `DANGER_AT`: 컨텍스트 주황·빨강 기준(%), `ORANGE` 등: 색
- `LIMIT_WARN_AT`, `LIMIT_DANGER_AT`: 한도 게이지 기준(%)

저장하면 바로 다시 로드됩니다.

## 토큰

사용량·채팅방·Git·메모 기능은 내 컴퓨터에서만 돌아 토큰을 쓰지 않습니다. `압축하기` 버튼만 Claude에게 요청을 보냅니다.
